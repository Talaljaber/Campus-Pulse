# CampusPulse v1-rc2: results (ML batch 4, P2)

Artifact `v1` sha `9a379d97c0cd` (models/frozen/v1, not released: no GitHub release was made in this batch).
Numbers come from `python services/ai/evaluate.py --all` (`reports/metrics.json`, `coverage.json`,
`fairness.json`, `ablations.json`), `reports/cv_p2.json` (train.py) and `reports/encoder_bakeoff.json`
(`scripts/encoder_bakeoff.py`); the tables below are generated by `python scripts/results_v2.py`.

**Protocol.** Only scenario-held-out OOF over the frozen `cv_fold` folds (LD-31) and the frozen model on our own
test set (pooled and per set). No random split anywhere. Model choices were made on OOF only. Our own test set
informed exactly two config switches, as P2.10 prescribes (`alpha_priority`, `mondrian_by_lang`). Every rc2
number trains on **official rows only**: the 501 augmented drafts are unreviewed (`needs_human_check=True`) and
appear only in the arm labelled **unreviewed**.

> earlier version of `data/our_test/our_test.csv`; `reports/benchmark.md` holds the current ones.

## What changed from rc1

- **Category vote (D-016):** M2-LR (C 0.5, pre-declared) + the new **department-prototype member `m2proto`**
  (D-014) at fixed equal weights; M1 and M2-kNN keep a category vector but have weight 0. Nothing is tuned on
  the 30 groups except two calibration temperatures chosen by OOF negative log-likelihood.
- **`m2proto`:** cosine similarity to (a) per-category prototypes learned inside each CV fold and (b) office
  descriptions embedded at train time (`config/office_descriptions.yaml`), softmax at T = 0.005.
- **Office descriptions provenance:** the first version was written by the ML agent after it had read the
  official training texts **and** the rc1 error table, which quotes our_test rows. To keep our_test honest, rc2
  uses a rewrite by a separate session that could read only the two reference documents (CHALLENGE_RULES and the
  public GJU pages). The decision was made on provenance before its scores were known; both variants are
  reported below.
- **Priority:** unchanged structure (members' average → head → safety floor). New: head temperature (OOF NLL picked
  1.0, so no change) and the safety lexicon now floors "people trapped in a stuck lift" (live rc1 finding).
- **Conformal:** the quantile uses the pooled-CDF rule over cv_groups (`group`: 30 groups, not 432 rows), and
  category quantiles are **per language** (`MondrianByLang`, P2.10 rule).
- **kNN memory floor:** `knn.memory_min_sim` 0.80 → 0.91, measured (`reports/memory_threshold.json`).
- **Encoder:** unchanged (e5-small int8, pruned); the release tarball is not rebuilt.

## Findings

- **Category generalisation improved on OOF (0.490 → 0.806), and the gain comes from `m2proto`.** Without it the
  ensemble falls to 0.561 (Δ −0.245, 90 % CI [−0.365, −0.145]). Neither prototype part works alone on our test
  set (learned only 0.614, office only 0.599 pooled); together they reach 0.789.
- **our_test is mixed.** Pooled category 0.710 → 0.789 and set2 (free student style) 0.663 → 0.719 improve, but
  **set1 (official style, unseen scenarios) drops 0.746 → 0.674** and **Arabizi drops 0.696 → 0.530** (32 rows,
  8 groups).
- **Arabic is still the weak slice.** OOF Arabic category 0.270 → 0.333 against English 0.573 → 0.966. The office
  descriptions are written in standard Arabic; the requests are Jordanian dialect. our_test Arabic improved more
  (0.522 → 0.758).
- **Priority did not move** (OOF 0.904, our_test 0.847; Arabizi 0.301). Its conformal sets still never widen on
  our_test (coverage 0.843, size 1.00). The OOF-only fixes did not help, because OOF says the head is
  calibrated: the group quantile rose 0.394 → 0.574 and the NLL-chosen head temperature is 1.0. The over-confidence
  shows only on new phrasing, which the official data cannot supply. The **unreviewed arm** raises our_test
  priority to 0.908 (+0.061): reviewed augmentation is the path, not a recalibration trick.
- **The D-016 checks agree with the fixed structure.** kNN in the category vote: Δ −0.049 [−0.120, +0.007] (out).
  M1 back in: Δ −0.053 [−0.133, 0.000] (out). The P2.7 tuned search: +0.021 [0.000, +0.060], below the +0.05 rule
  and 0.000 on our_test (not adopted). Dropping M2-LR: +0.021 [0.000, +0.060] (rule not met, kept).
- **Evidence features carry priority** (removing them: OOF −0.316, our_test −0.249). **Wrapper stripping**
  matters for category OOF (−0.054) and our_test priority (−0.067).
- **"today" shortcut (LD-34):** masking every `deadline_today` span in our_test costs priority 0.847 → 0.787
  (−0.061). The reliance is real but partial. The deadline-shortcut probes (P2.5, not written yet) will measure it
  directly.

  priority: EN 0.876 < 0.90). The per-language quantiles come from OOF scores: Arabic has 15 groups, so the group
  rule needs the largest Arabic score (q = 0.938) and **Arabic category sets hold about 6 labels**; English
  gets q = 0.668 and **under-covers on our_test (0.856)**; Arabizi has no calibration rows and keeps the global q.

  review. Reviewed Arabic/Arabizi augmentation adds calibration groups and shrinks it. The switch is
  config-only (`conformal.mondrian_by_lang`, then `train.py --retune`) if the lead prefers the global quantiles.

## Caveats (read before quoting a number)

- **Thin data (LD-32):** 432 official rows are 42 texts in 30 groups; read OOF numbers as ±0.1. Bootstrap
  intervals over 30 groups are wide, and several "no change" arms are exact ties because the change does not
  touch the category vote.
- **Our test set is LLM-written (D-010)** and, like the new-scenario drafts and the office descriptions,
  by the same model family. Shared priors between test and helper text cannot be ruled out.
- **The office descriptions are not fully independent of the training data's domain:** the clean rewrite read
  only the challenge definitions and public pages, but those definitions were written with the official
  examples in view. OOF of the office part is less held out than the learned part (learned-only OOF 0.597).
- **The priority lexicons and the danger lexicon were written after reading every official row**, so OOF
  priority is optimistic; set1/set2 are the cleaner check (0.78 both).
- **Conformal coverage is approximate** (effective n about the number of groups; 15 for Arabic).
- **Unreviewed rows:** every augmented number above trains on unchecked drafts; treat them as an upper-bound
  preview of P2.4.
