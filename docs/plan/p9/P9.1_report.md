## Deviations from PLAN.md

- `TicketOut.clock_started_at` is required; when the entity has `None` (row from before the migration or a fake) the presenters fall back to `sla_due_at`. Documented in code.
- The Arabic chat sentence "تذكرتك X صارت {status}" needs a feminine adjective, so `chat.status.solved` is "محلولة" and `chat.status.new` is "جديدة"; `staff.status` uses "تم الحل" and "جديد" as briefed.
- Tests: the old Linear test "escalation changes only the priority" relied on the `escalated: null` state mapping; it now overrides `in_progress: null` to keep covering the null-state branch. `build_test(booking_route=True)` re-creates the old booking cell so the booking code stays tested while the shipped config no longer routes it.
