## Deviations and decisions

- Error toasts: a 422 shows the server message (`transition ... not allowed`); 401/403/404/waking/other show our dictionary sentence (server prose is English, the UI is bilingual). The brief said the server message for 403/404 too.
- Internal note and status: the status picker is disabled in internal-note mode and the request sends `status: null` (an internal note never changes the status, row 4). A public reply on a finished ticket (solved, closed) is disabled with a hint, because the state machine has no staff-comment row for those states; use the status form to reopen.
- Priority change and forward are shown only while the ticket is running (rows 9, 10); a merged ticket shows "no actions".
- The Linear link badge of the old card list is not in the new table or workspace (the plan's columns do not list it). `ticket_links` reads remain in `useTicketQueue`.
- The old Review tab (confirm / correct a review item) and Incidents / Flags tabs are removed from `/staff` as specified; `ReviewQueue`, `CorrectionForm`, `IncidentsPanel`, `useReviewQueue` stay in the tree unused (their unit tests still run). Incident resolve lives on `/pulse` (covered by `pulse-basic`); the correct-a-review-item e2e flow no longer has a UI entry point.
- `HintRow` lives in `lib/tickets/types.ts` (components may not import repos by lint rule).
