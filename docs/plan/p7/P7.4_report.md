# P7.4 report: LLM front end (translate Arabic and Arabizi, plus an internal explanation)

Model (pinned, user decision): `deepseek/deepseek-v4.1-flash`, temperature 0, top_p 1, seed 42, JSON-schema
output, reasoning off (`reasoning: {enabled: false}`), max 600 tokens, 8 s timeout, one retry, 8 parallel workers,
SQLite cache. Config: `config/llm_frontend.yaml`. Flag: `--use-llm` or `LLM_FRONTEND=true` plus
`OPENROUTER_API_KEY`. `--use-llm` now selects this front end (it supersedes the P2.20 Arabizi translator, which
stays reachable through `LLM_ARABIZI_TRANSLATE` alone). Without a key or flag nothing changes (offline, opus-mt).

Flow: English text is classified directly; Arabic and Arabizi texts are replaced by the LLM's English in front of
the encoder only. One call per row returns `english`, `explanation` and the P8.5 cues. A failed or invalid reply
leaves the text unchanged, so the shipped opus-mt path takes over for that row. Guards, langid, floors, M1 and
conformal read the original text. The explanation is an internal column: it is kept in `encoder.records`, never in
a DTO, and written only to `data/derived/llm_explanations.csv`. The model is the unretrained frozen one.

Early finding: with reasoning on at 400 tokens, 45 percent of replies were empty or truncated; reasoning off and
600 tokens gives 100 percent valid replies. Empty replies are no longer cached.

## Latency (uncached, per call, ms; tune / check)

| lang | p50 | p95 |
|---|---|---|
| en | 790 / 812 | 1866 / 1942 |
| ar | 774 / 822 | 1207 / 1990 |
| az | 879 / 752 | 3175 / 2695 |

Calls inside a batch run in parallel; per-request latency is about one call. English rows also make the call
(explanation only), which adds that latency to the request unless the caller makes it asynchronous
(`explain_english: false` in the yaml removes it).

Spend: USD 0.011 per 108 calls (about USD 0.0001 per row). JSON validity 100 percent (108/108 on both splits),
fallback rate 0 percent for Arabic and Arabizi. English rows whose `english` differs from the input: 13/40 tune,
12/40 check (whitespace, casing and light normalisation; the English text is never used, so labels are untouched;
the 40 includes 4 Arabizi rows with no detected transliteration that take the English path as today).
