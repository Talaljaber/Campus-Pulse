# P7.1 report: `empty_set` to human review, true set sizes, shared harness

## What changed

- `domain/policy.py`: new rule `RULE_EMPTY = "b2_empty"` between `b_ood` and `c_accept`. A core carrying the
  flag `empty_set` goes to `HUMAN_REVIEW`. It is also evaluated after an escalation. `POLICY_RULES` and the
  class docstring are updated. Gibberish and the wide-set OOD rule still win.
- `application/services/triage_core.py`: an empty conformal set is still replaced by the argmax singleton
  (labels unchanged). It now also adds `empty_set_cat` / `empty_set_pri` next to `empty_set`. A set that a
  category answer or a priority floor replaced is a real singleton, so it does not raise the flags (before,
  `empty_set` could be set for a floored row whose empty set had been overwritten).
- `application/services/llm_merge.py`: a merge that ends in an empty set adds the same per-target flags.
- `application/use_cases/batch_predict.py`: the debug columns `set_cat` / `set_pri` are `0` when the
  respective flag is set. `validate_predictions.py` needs no change (it does not read those columns; the
  `empty_input` path already wrote 0).
- Online: the review item keeps the reason `needs_review` (the DB and DTO reason set is unchanged). The
  trace's `policy_path` ends in `b2_empty` and the response flags carry `empty_set`.
  `empty_set_cat` / `empty_set_pri` are internal: they are deliberately NOT added to `values.FLAGS`, so the
  API enum, `types.gen.ts` and the contract tests are untouched (`flags_out` drops them).
- `scripts/scratch_model.py` (new) and `scripts/dev_eval.py` (new), see below.

## Paste-ready text for the lead

### models.md `## 34. Empty conformal set goes to human review (P7.1, D-029)`

An empty conformal set means no label reached the threshold. The core still outputs the argmax singleton, so
every scored label is unchanged, but the set is no longer an auto-answer. `TriageCore` raises `empty_set`
plus `empty_set_cat` / `empty_set_pri` (internal, not in the API enum). `DefaultDecisionPolicy` gets rule
`b2_empty` (after `b_ood`, before `c_accept`, also after an escalation): `empty_set` gives `HUMAN_REVIEW`,
recommended over ASK because a two-way question on an empty set is a guess. `predict.py --debug` prints
`set_cat` / `set_pri` = 0 for an empty set, so the evaluator's bucketing counts the row as not auto. Floors and
answered categories are real singletons and do not raise the flags. Gate: pure routing, tests plus label identity
(432 official rows byte-identical; OOF and our_test macro-F1 unchanged). Tools added: `scripts/scratch_model.py`
(lexicon scratch model with a rewritten manifest) and `scripts/dev_eval.py` (run and score `data/dev_fixes`, paired
group bootstrap vs a base).
