## What ran

  (`.cache/model_panel.sqlite` via `CachedChat`). 627 rows x 3 models = 1881 calls, 0 failures.

## Rule and result (`scripts/model_panel.py decide`)
- keep: >= 4 of 5 votes (4 of 4 without a checker) agree on category AND priority, equal the draft, and nobody calls
  the text unnatural. fix: 3 new votes + checker agree on a label different from the draft (new scenarios only), no
  form of the scenario kept. drop: >= 2 of the 3 new voters say unnatural/off-topic. Else blank (stays out).
- Result: **keep 447, fix 0, drop 0, blank 180.** Nobody reached the fix bar (the 3 new votes never matched the checker
  against the draft); no text was called unnatural by 2 new voters (glm 5 rows, gpt 0, qwen 0; checker 28). 7 rows
  were blocked from a fix by a conflicting form inside the same scenario (NEW-C06/C26/C34/C74), so they stay blank.
- `review_queue.py apply --queue review_queue_model_panel.csv --model-panel --dry-run`, then apply: keep=447 fix=0
  drop=0; no file content changed (a keep does not touch rows). Guard conditions belong to `--accept-agreed` only,
  which was not used; `--skip-guard` was not used.

Reading: category is easy and all voters agree (0.91-0.97), so the category labels are well supported. Priority is the
contested axis. gpt-4o-mini is a poor priority voter (kappa 0.37-0.45 against everyone, it over-assigns high/medium),
so in practice the keep rule leans on qwen, glm, the draft and the checker. Qwen and GLM agree with each other and
with the draft far more than they are independent evidence (qwen-draft joint agreement 0.89): shared reading of the
medium/high "today" cases is possible and a 4-of-5 keep is not as strong as five independent human judgements. Treat
the arm as "plausibly correct", not as verified.
